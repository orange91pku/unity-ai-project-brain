# Unity AI Project Brain package

This package installs the read-only Unity Editor bridge for Unity AI Project
Brain.

Open **Tools > HeyCici > Project Brain** to:

- inspect Unity project and Git repository identity;
- verify Force Text serialization;
- copy a versioned project-context snapshot;
- copy backend installation and Context API commands;
- open the complete installation guide.

The package never edits Unity assets, starts external processes, or embeds a
private project index. The Python/GitNexus backend remains a separate,
explicitly installed service.

Full documentation:
<https://github.com/orange91pku/unity-ai-project-brain/blob/main/docs/UPM_INSTALL.md>
